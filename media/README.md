# Financial calculations checked against your rules | GERO

A short service demonstration using a public Apache Fineract component case.
Seven grace days within fourteen days should represent 0.5 under the declared
contract. The tested version returns 2.

GERO turns written calculation conventions into executable checks. A scoped
engagement delivers a report, repeatable tests and a candidate correction where
supported. The customer-specific version and conventions require their own review.

Public evidence: https://www.gero.uz/research/fineract-calculation-contracts/
Code and reproduction: https://github.com/kadyrbekovhamit-cyber/gero-fineract-calculation-contracts
Upstream inverse-helper correction: https://github.com/apache/fineract/pull/6409

The public example uses synthetic inputs and pinned source versions. It does not
establish production exposure, customer losses or a security vulnerability.
25 common checks pass on locally corrected code, plus 144 additional calendar
cases verified only on that correction. Only the inverse-helper correction is
already merged upstream; the other rule families reproduce previously reported issues.
